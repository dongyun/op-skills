# 音色选择与交互

以下为技能的中文风格标签；它们是方便选择的近似描述，不是官方听感评级或 SSML 风格。基础参数均为 `rate: "+0%"`、`pitch: "+0Hz"`，不以变调冒充另一种声音。

| 展示名称 | 提示 | 内部声线 ID |
|---|---|---|
| 淳厚男声 | 沉稳端正，适合长文、知识解说 | `zh-CN-YunyangNeural` |
| 清朗男声 | 清晰自然，适合访谈、科技内容 | `zh-CN-YunxiNeural` |
| 甜美女声 | 柔和亲切，适合故事、日常讲述 | `zh-CN-XiaoxiaoNeural` |
| 活泼女声 | 轻快明亮，适合轻松内容 | `zh-CN-XiaoyiNeural` |

“淳厚男生”“甜美女生”按同名男声、女声识别。用户要求其他风格或语言时，可在本次真实声音列表中查找候选并说明描述边界，不能编造声线 ID。某候选下线时，保留原选择和不可用记录，询问替代选项。

## 单人稿：两个选择框

调用当前环境的 `request_user_input_async`，参数例：

```json
{
  "questions": [
    {
      "title": "这份文字稿想用哪种音色朗读？",
      "options": ["淳厚男声 · 沉稳端正", "清朗男声 · 清晰自然", "甜美女声 · 柔和亲切", "活泼女声 · 轻快明亮"]
    },
    {
      "title": "是否同时生成一张与文稿主题相符的方形封面？",
      "options": ["仅生成音频", "音频＋主题封面"]
    }
  ]
}
```

首项可按文稿类型推荐，但推荐不等于用户确认。仅缺封面偏好时只问第二题。

## 多角色稿

保留稿件角色。对每个未指定音色的角色展示一题，例如：

- “男主持用哪种音色？”→ 淳厚男声、清朗男声。
- “女主持用哪种音色？”→ 甜美女声、活泼女声。
- “是否同时生成主题封面？”→ 仅生成音频、音频＋主题封面。

无性别角色可以提供四种音色。角色很多时分批询问；已有的明确选择不重新提问。用户指定所有角色共用某种音色时尊重其要求。

## 记录

把 `selection_basis` 写成用户原始选择的简短摘要，如“本次选择框：淳厚男声；仅生成音频”。明确让模型代选时记录“用户授权代选”及最终选型理由，不能把模型推荐记录成用户已选。

本技能的预置 ID 参考 [Microsoft 声音目录](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/language-support?tabs=tts)。Azure 名录不保证 Edge 服务可用；实际运行按 [edge-tts 的声音列表](https://github.com/rany2/edge-tts#changing-the-voice)核验。本次技能制作没有查询在线声线，也没有试听这些组合。
