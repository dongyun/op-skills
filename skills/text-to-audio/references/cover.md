# 可选主题封面

仅用户选了“音频＋主题封面”或已经明确要求封面时执行。用户要求沿用某张图片时按该要求处理，不另外生成。

1. 从稿件提取主题和一个具体视觉意象。默认一张 1:1 方形插画，构图简洁、缩略图可辨；不擅自增加人物肖像、品牌标识或无来源事实。默认无文字，用户要求标题时使用其确认标题。
2. 优先使用内置 `image_gen` 工具；可用时读取 `imagegen` skill。新图仅提交主题与视觉要求，不传无关全文。不能用程序绘制占位图声称已完成图像生成。图像编辑先检查用户提供的原图。
3. 生成后使用工具实际返回的本地路径，把选定文件复制到本次输出目录的 `cover.png`（若实际格式为 JPEG 则保留 `.jpg`），查看图像，核对主题、比例、裁切和可读性。不要假定工具支持输出目录参数。
4. 保存 `cover_record.json`：`status`、实际路径、SHA-256、宽高、提示词、生成工具名称及检查结果。成功写 `PASSED`，用户明确不需要时 `NOT_REQUESTED`；仍待选择时 `PENDING`；请求失败写 `FAILED`。没有真实文件时不填成功路径。
5. 工具不可用或失败时保存已完成音频，交付记录标出封面未完成。不自动改用收费 API 或要求用户提供密钥。续作只补封面，无需重合成音频。

封面是独立文件，默认不嵌入 MP3，不修改已经核验的音频字节。用户另外要求嵌图时更新哈希和技术验收，不能继续沿用旧收据。
